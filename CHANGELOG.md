# Changelog

## 2.0.0

- Named playthroughs and checkpoints, retained history, and explicit recovery.
- Nested read-only save inspection and automatic dock refresh.
- Validated loads, typed data, migration errors, and autosave retry limits.
- SaveComponent setup and duplicate-identity checks.
- Working demo at the repository root; no addon copy step.
- Correct plugin handling for resource UIDs and exported games.

Existing low-level APIs remain available. Back up saves before adopting sessions; see [Upgrading](GUIDE.md#upgrading).

## 1.2.0

Typed keys, debounced autosave, ordered migrations, JSON export, SaveComponent, CollectionLink, and the Lite save/load menu.

Earlier versions remain available in [GitHub Releases](https://github.com/youssof20/savestate/releases).
