# Lite demo

Open `project.godot` at the repository root and press F5. The addon is already included and enabled.

Move with the arrow keys, change the values, and save. Stop and run again to resume. Save a named checkpoint, change the state, then load the checkpoint to restore it. Inspect the same saves in the editor's SaveState dock.

`main.gd` shows the session API, typed values, named saves, and load confirmation. The demo saves to `user://savestate-lite-demo-v2`.
